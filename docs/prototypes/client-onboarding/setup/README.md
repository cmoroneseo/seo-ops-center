# New Client setup modal

Serve the parent prototype folder, then open http://127.0.0.1:4173/setup/?v=1.

Click **New Client**, choose Monthly or Custom, and configure the scope. Picker directions: Stepper, Split, Compact. Keys: 1–3, arrows, R. Draft edits stay in memory across layout changes; reload resets them. Creation, plan/tasks and Basecamp import use demo state only.

The original onboarding-tab exploration is retained in the parent directory for reference. The modal is now the active exploration. No production components are modified.
